## Project Overview

This repository contains the code and assets behind my Web CV 2.1, which serves as the main page of my personal portfolio.

Its purpose is to showcase my **Fullstack development skills**, emphasizing **clean code, modular architecture, accessibility, security, and internationalization**.

### Technical Focus

- `HTML5`, modular `CSS3`, `Vanilla JS` (ES modules), secure & maintainable `PHP`, `i18n` with `JSON`, accessibility, scalable `SVG`

### Documentation & Guidelines

For agents, IDEs, or technical reviewers:

**Repository Files:**

- [README.md](./README.md) — project overview and multilingual presentation
- [DESIGN.md](./DESIGN.md) — design decisions and architecture
- [CHANGELOG.md](./CHANGELOG.md) — version history and notable changes
- [AGENTS.md](./AGENTS.md) — instructions for coding agents, automation, and tools
- [CONTRIBUTING.md](./.github/CONTRIBUTING.md) — contribution scope and review guidelines
- [CODE_OF_CONDUCT.md](./.github/CODE_OF_CONDUCT.md) — expected conduct and reporting inappropriate behavior
- [SECURITY.md](./.github/SECURITY.md) — security practices and private vulnerability reporting

> *This project is personal and primarily for learning and portfolio presentation.* However, it is structured and documented with professional standards in mind.
