## Project Overview

This repository contains the code and assets behind my Web CV 2.1, which serves as the main page of my personal portfolio.

Its purpose is to showcase my **Fullstack development skills**, emphasizing **clean code, modular architecture, accessibility, security, and internationalization**.

### Technical Focus

- `HTML5`, modular `CSS3`, `Vanilla JS` (ES modules), secure & maintainable `PHP`, `i18n` with `JSON`, accessibility, scalable `SVG`

### Documentation & Guidelines

For agents, IDEs, or technical reviewers:

**Repository Files:**

- [README.md](./README.md) — project presentation, multilingual overview
- [AGENTS.md](./AGENTS.md) — automation, AI, and tooling rules
- [CONTRIBUTING.md](./.github/CONTRIBUTING.md) — guidelines for understanding, reviewing, and learning code
- [SECURITY.md](./.github/SECURITY.md) — security practices and reporting
- [CODE_OF_CONDUCT.md](./.github/CODE_OF_CONDUCT.md) — expected behavior and reporting inappropriate conduct
- [CHANGELOG.md](./CHANGELOG.md) — (unfinished)
- [DESIGN.md](./DESIGN.md) — (unfinished)
